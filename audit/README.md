# Сверка ТЗ и реализации (ноябрь 2026)

Три read-only аудита (продажи/склад, товары/отчёты, настройки/модули) нашли около 180 расхождений. Работа идёт пакетами; закрытое отмечено в коммитах `audit:`.

Приоритет High (на момент аудита):
- Продажа: доставка (адрес/телефон), списание бонусов и кэшбэк, сохранение всего чека при «Отложить».
- Товар: сохранение стирало флаг «важный»; нет «Создать копию», «Массовое редактирование», ссылки на экспорт/импорт.
- Отчёты: нет таблицы «Товары за сегодня»; клиенты: режимы поиска по дате без фильтра даты; ревизии: нет отчёта и группировки по датам.
- Остатки: «+» категории → заказ поставщику; карточка товара без баланса периода.
- Приёмки: фото накладной, поле штрихкода; заказ поставщику: остаток/продажи/списания/порог в карточках.
- Настройки: иконки и текст методов оплаты/покупки, счёт зачисления; отрицательная надбавка метода покупки; настройки продаж (поля, доставка) без UI; сброс данных организации; поля шаблона печати; применение черновика ИИ без просмотра.
- Не делаем (внутренняя система): восстановление пароля по почте, 4-шаговая регистрация, поддержка/чат.

## Закрыто (коммиты `audit:`)
Касса: доставка (адрес/телефон), списание бонусов, кэшбэк, постоянная скидка клиента, «Отложить» с полным чеком, настройки продаж (поля, объединение позиций, «Отложить»), иконки и подписи методов, метод покупки со скидкой (отрицательная надбавка), страница продажи (оплата, клиент, надбавка, бонусы, печать накладной).
Товары: флаг «важный» не стирается, «Создать копию», себестоимость составного, массовое редактирование, ссылки на экспорт/импорт.
Отчёты и клиенты: таблица товаров, фильтр дат в режимах клиентов, отчёт и группировка ревизий, комментарий ревизии.
Склад: баланс периода в карточке товара, «+» категории → заказ поставщику, остаток/продажи/списания/порог в карточках заказа, фото накладной, штрихкод, комментарий.
Настройки: валюта и знаки, внешний вид, выбрать все/очистить и фильтр модулей в ролях, подсказка пароля, показать пароль, платежи по дате создания/периоду, диапазон дат обновлений, простые продажи в комплексных, поля печати (покупатель/телефон/адрес).

## Сознательно не делаем
Сброс данных и удаление организации (опасно, система внутренняя), восстановление пароля по почте, поддержка/чат.

## Осталось
Счёт зачисления методов оплаты (выручка не зачисляется на счета), настройки продаж по филиалам, ЗП: календарь часов и тип бонусов, отчёт по смене, Excel-экспорт, P&L: справочные строки, подписи/картинки в шаблоне печати, предпросмотр этикетки, значки главной.
