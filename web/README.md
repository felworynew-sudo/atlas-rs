# Atlas Web

Интерфейс Атласа: React 18 + TypeScript + Vite. Работает поверх Rust API (`../crates/api`).

## Запуск
```bash
# 1. сервер (из корня репозитория); порт 8080 в некоторых системах закрыт, поэтому 8787
DATABASE_URL=postgres://postgres:secret@127.0.0.1:54329/atlas JWT_SECRET=dev BIND=127.0.0.1:8787 cargo run -p atlas-api

# 2. интерфейс (из папки web); /api проксируется на ATLAS_API (по умолчанию http://127.0.0.1:8787)
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # проверка типов + сборка в dist/
npm test           # юнит-тесты (расчёт чека, клиент API)
```

## Что готово
- Вход и регистрация компании; сессия в `localStorage`, выход по клику на имя.
- Тёмная/светлая тема (токены из `design-system.md`), адаптив: главная 4×3 или 2 колонки, «Новая продажа» — две колонки или одна.
- **Главная:** выбор филиала, статистика (`/api/reports/home`), плитки по правам и модулям; ещё не перенесённые экраны затемнены.
- **Новая продажа:** каталог с поиском и категориями, остатки (красным при низком), чек с ±, кастомный продукт, клиент (поиск), метод покупки и оплаты, скидка, сдача и быстрые купюры, «Отложить» и «Открытые чеки», итог от сервера, идемпотентный запрос.
- **История продаж:** фильтр по датам и филиалу, группы по дням, карточка продажи, возврат (деньги/замена, на склад, причина), удаление продажи.
- **Товары:** список по категориям с остатками, форма товара (цены по филиалам, штрихкоды, остаток, категория/поставщик/единица).

## Не перенесено
Комплексные продажи, остатки/приёмки/списания/ревизии, расходы, отчёты, клиенты, настройки, смены, зарплата, чеклист и остальные экраны из ТЗ; составные товары в форме товара; смешанная оплата.
