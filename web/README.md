# Atlas Web

Интерфейс Атласа: React 18 + TypeScript + Vite. Работает поверх Rust API (`../crates/api`).

## Запуск
```bash
# 1. сервер (из корня репозитория); порт 8080 в некоторых системах закрыт, поэтому 8787
DATABASE_URL=postgres://postgres:secret@127.0.0.1:54329/atlas JWT_SECRET=dev BIND=127.0.0.1:8787 cargo run -p atlas-api

# 2. интерфейс (из папки web); /api проксируется на ATLAS_API (по умолчанию http://127.0.0.1:8787)
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # проверка типов + сборка в dist/
npm test           # юнит-тесты (расчёт чека, клиент API)
```

## Что готово
- Вход и регистрация компании; сессия в `localStorage`, выход по клику на имя.
- Тёмная/светлая тема (токены из `design-system.md`), адаптив: главная 4×3 или 2 колонки, «Новая продажа» — две колонки или одна.
- **Главная:** выбор филиала, статистика (`/api/reports/home`), плитки по правам и модулям; ещё не перенесённые экраны затемнены.
- **Новая продажа:** каталог с поиском и категориями, остатки (красным при низком), чек с ±, кастомный продукт, клиент (поиск), метод покупки и оплаты, скидка, сдача и быстрые купюры, «Отложить» и «Открытые чеки», итог от сервера, идемпотентный запрос.
- **История продаж:** фильтр по датам и филиалу, группы по дням, карточка продажи, возврат (деньги/замена, на склад, причина), удаление продажи.
- **Товары:** список по категориям с остатками, форма товара (цены по филиалам, штрихкоды, остаток, категория/поставщик/единица).

- **Остатки и склад:**
  - `/stocks` — остатки по филиалу: сводка по закупочной и продажной цене, «Важные продукты», группы по категориям, «7дн. продажи/списания»;
  - `/stock/:id` — карточка товара: порог подсветки, «важный», быстрые действия и журнал движений с балансом по видам;
  - `/supplies`, `/supply/:id` — приёмки: возврат поставщику, обновление закупочных цен, оплата со счёта, удаление;
  - `/supply-orders`, `/supply-order/:id` — заказы поставщикам: статусы, предложение по порогу остатка, кнопка «Принять» (приёмка по заказу);
  - `/writeoffs`, `/writeoff/new` — списания с причиной и суммой по себестоимости;
  - `/revisions`, `/revision/:id` — ревизия по категории с расхождением в рублях.

- **Расходы:** `/spendings` (список по датам и филиалам, итог, удаление), `/spending/new` (категория, детали, сумма, источник — денежный счёт, дата, операционный или капитальный).
- **Отчёты:** `/reports` (ссылки и сводная таблица «Сегодня»), `/reports/sales` (группировка по оплате, покупке или сотруднику, графики по дням), `/reports/profit` (P&L), `/reports/products` (три таблицы с выбором колонок; режим «Отчет по списаниям»), `/reports/revisions`; везде «Экспорт в CSV». Период передаётся датами, сервер считает сутки по часовому поясу филиала.

- **Клиенты:** `/clients` (статистика за период, четыре режима поиска, новый клиент), `/client/:id` (поля, постоянная скидка, уровень бонусов, начисление/списание бонусов, карта «N-й в подарок», статистика, история покупок).
- **Настройки** `/settings`: сотрудники (создание, роль, филиалы, пароль, деактивация), роли и права по модулям, филиалы, поставщики, категории, единицы, денежные счета, методы оплаты и покупки, скидки, причины возвратов и списаний, категории расходов, ежемесячные расходы (универсальный список `CrudList`), настройки организации с включением модулей, лояльность, настройки продаж.

- **Смена** `/shift`: открытие с суммой в кассе, итоги по наличным (начало, продажи, возвраты, изъятия, расходы, оплаченные приёмки, внесения, итого) и по QR/терминалу, продажи по сотрудникам, изъятие/внесение, сотрудники смены, закрытие с фактом по каждому способу оплаты и недосдачей, история смен, «Отменить закрытие».
- **Зарплата** `/salary`: начислено, выплачено и к выплате за период, детали сотрудника (часы, выплаты, баланс за период и за всё время), «Выплатить» со счёта.
- **Чеклист** `/checklist`: задачи дня с отметкой «Выполнено время, сотрудник», разовые и ежедневные задачи, разделы, режим редактирования.
- **Комплексные продажи** `/complex-sales`, `/complex-sale/:id`: список (активные, даты, филиал), форма с шаблоном, клиентом, статусом, расходами (товары со склада и свои), ценой и ожидаемой прибылью, оплаты по счетам, история и комментарии, шаблоны.
- **Заказы от клиентов** `/client-orders`: список, карточка заказа, смена статуса, «Создать продажу».
- **Перемещения** `/transfers`, `/transfer/new`: между филиалами, состав и удаление.
- **Производство** `/manufactures`, `/manufacture/new`: готовый товар, количество, партия, ингредиенты и себестоимость партии с сервера.
- **Платежи** `/payments`: список с фильтрами, новый платёж с периодом, «Движение денег» по счетам (начало, поступления, выплаты по видам, конец).
- **Обновления** `/updates`: лента изменений, при открытии помечается прочитанным.
- **Печать этикеток** `/labels`: товары и число копий, дата, настройки макета, печать из браузера.
- **Составные товары** в форме товара: состав с количествами, «Производится заранее» / «Списывается при продаже».
- **Смешанная оплата** в «Новой продаже»: два способа, сумма первого, остаток автоматически на второй.
- **Настройки** (дополнено): онлайн-каталог, экспорт/импорт CSV (товары, продажи, производства; пробный прогон и отмена импорта продаж), API-токены с журналом (секрет виден один раз), черновики от ИИ-агента (применить создаёт продажу или приёмку), профиль со сменой пароля.

## Не перенесено
Не перенесены «Ценовые категории», «Модификаторы товаров», «Настройки печати» как отдельный раздел, справка, правовая информация, внешний вид; светлая тема и телефонная раскладка новых экранов визуально не проверены.
